# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.2 - 2026-05-14

### Added
- GitHub repository scanning support
- Multi-agent LangGraph architecture (Logic, Security, Style, Code Fixer)
- Comprehensive HTML dashboard generation
- SHA-256 content hashing for LLM cost savings
- Exponential backoff retry logic for rate limit resilience
- CLI with batch processing and configurable LLM providers (Groq/OpenAI)
- CI/CD gating via GitHub Actions
